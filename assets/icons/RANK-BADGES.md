# FitQuest rank badges

Original SVG artwork created for FitQuest. These are not Riot Games or League of Legends assets.

Total Level milestones: Bronze 10, Silver 25, Gold 50, Platinum 75, Emerald 100, Diamond 150, Master 200, Grandmaster 250.

Existing achievement IDs and unlock requirements are preserved.

The evolved set uses a shared beveled star shield, with laurels, wings, gems, ribbons, and crowns added at higher ranks. Every asset retains a transparent 160×160 viewBox. Rank-up displays grow from 104px (Bronze) to 160px (Grandmaster); header controls retain their existing touch-target size.

Regenerate the artwork from the repository root with `python scripts/generate-rank-badges.py`. Palettes and tier decorations live in that script.
